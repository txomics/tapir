5  Splicing Event Detection using plyxp + splicelogic

Following differential transcript usage (DTU) analysis (e.g., using satuRn), we may next want to examine the specific splicing events (skipped exons, alternative splice site usage, or entron retention, e.g.) underlying observed transcript-level differences.

In this chapter, we demonstrate how to use plyxp and splicelogic together to compute and visualize condition-specific isoform proportions and detect skipped-exon events, using simulated transcripts.

5.1 Setup and Dependencies

library(SummarizedExperiment)
library(plyxp)
library(plyranges)
library(splicelogic)
library(here)

# Simulation helper functions
source(here("scripts", "demo_sims.R"))

5.2 Simulating Transcript Abundances

To illustrate the workflow, we simulate a minimal SummarizedExperiment containing 2 genes with 2 isoforms each across 6 samples (3 control vs. 3 treated).

  • Gene A: Undergoes isoform switching upon treatment (switching from isoform 201 to isoform 202).
  • Gene B: Isoform ratios remain unchanged across conditions.
set.seed(5)
se <- simulate_se(n_per_group = 3)

5.3 Computing Isoform Proportions with plyxp

We will start by using plyxp to wrap our SummarizedExperiment. This allows us to further manipulate the rows (features) and columns (samples) of our dataset using fast and intuitive tidy grammar. Here, we group by gene_id across rows to compute the relative isoform proportion per sample:

\[\text{Isoform Proportion} = \frac{\text{Counts}_{\text{isoform}}}{\sum \text{Counts}_{\text{gene}}}\]

xp <- se |>
new_plyxp()

# Compute isoform proportions per sample within each gene
xp <- xp |>
group_by(rows(gene_id)) |>
mutate(
  iso_prop = t(t(counts) / colSums(counts))
) |>
ungroup()

# Inspect computed proportions
assay(xp, "iso_prop") |> round(2)
        s1   s2   s3   s4   s5   s6
A-201 0.81 0.79 0.85 0.24 0.23 0.27
A-202 0.19 0.21 0.15 0.76 0.77 0.73
B-201 0.45 0.47 0.44 0.50 0.54 0.50
B-202 0.55 0.53 0.56 0.50 0.46 0.50

Let’s check our work by comparing these empirical proportions against the true simulation means (\(\mu\)):

# Ground truth means for Gene A isoforms (201 and 202)
assay(xp, "mu")[1:2, ]
      s1 s2 s3 s4 s5 s6

5.4 Summarizing Statistics per Condition

Next, we summarize the mean and standard deviation of isoform proportions within each condition (control and treated):

iso_stats <- xp |>
  group_by(cols(condition)) |>
  summarize(
    mean = rowMeans(iso_prop),
    sd = rowSds(iso_prop),
    cols(.samples = unique(condition))
  )

# Inspect mean and SD matrices
assay(iso_stats, "mean") |> round(2)
      control treated

We now append the per-condition summary statistics (mean and sd) to each transcript’s exon annotations, matching by tx_id (transcript ID):

exons <- exons |>
  mutate(
    mean_ctl = assay(iso_stats, "mean")[tx_id, "control"],
    mean_trt = assay(iso_stats, "mean")[tx_id, "treated"],
    sd_ctl   = assay(iso_stats, "sd")[tx_id, "control"],
    sd_trt   = assay(iso_stats, "sd")[tx_id, "treated"]
  )

5.6 Identifying Skipped Exons with splicelogic

Now that we have a summary of exonic effects per condition, we can characterize the types of splicing events underlying the observed changes using splicelogic

Here, we will use splicelogic to identify skipped exons. A skipped exon (SE) event is defined when an exon present in a transcript with a negative DTU coefficient is spliced out (skipped) in a positive-coefficient transcript of the same gene. (this is confusing - visual?)

5.6.1 Preprocessing Exon Metadata

The preprocess() function from splicelogic designates the coefficient column and retains relevant metadata for downstream reporting:

exons <- exons |>
  preprocess(
    coef_col = "coefficient",
    additional_columns = c(
      "pvalue",
      "mean_ctl", "mean_trt",
      "sd_ctl", "sd_trt"
    )
  )

5.6.2 Finding Skipped Exons

In practical analyses, you would typically filter for statistically significant transcripts (e.g., FDR \(< 0.1\)) before running event detection. Here, we analyze all transcripts to evaluate both Gene A and Gene B:

skipped <- exons |>
  find_skipped_exons()

# Select key summary columns
skipped |>
  select(
    gene_id,
    pvalue,
    up_pvalue = event_pvalue,
    ctl = mean_ctl, 
    trt = mean_trt,
    up_ctl = event_mean_ctl,
    up_trt = event_mean_trt
  )

5.6.3 Interpretation of Results

  • Gene A: Two transcripts show significant DTU. The transcript containing the cassette exon is down-regulated upon treatment (mean proportion drops from \(0.80 \rightarrow 0.20\)), while the isoform excluding this exon is up-regulated (\(0.20 \rightarrow 0.80\)). find_skipped_exons() successfully pinpoints this coordinates-level cassette exon event.
  • Gene B: No significant isoform shift occurs between conditions.
